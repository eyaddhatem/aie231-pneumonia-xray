# Milestone 1 explanation (for the oral exam)
1. Why recall on pneumonia: missing a sick child costs more than a wasted second look. Accuracy lies when one class is ~3/4 of the data (always-pneumonia scores high).
2. Why we count duplicates and patients: the same child's X-rays in train and test would inflate test scores (leakage).
3. Why look at image size / brightness per class: a CNN can cheat on non-medical clues.
4. The findings table at the end of the notebook is the bridge from EDA to every later decision.
